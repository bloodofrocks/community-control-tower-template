# Security and privacy

Please do not report credentials, private CVs, personal contact data, or
spreadsheet contents in a public issue.

## Before publishing a copy

- Remove spreadsheet IDs, deployment IDs, OAuth files, API keys, tokens, and
  personal data.
- Keep your own Sheet and Apps Script project private.
- Use Apps Script Properties or another secure configuration store for secrets.
- Review sharing permissions for every connected Google service.

For a suspected security issue in this template, contact the repository
maintainer privately through GitHub before opening a public issue.
