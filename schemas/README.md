# Workbook schemas

Create these tabs in your own Google Sheet and use the CSV files as the
starting headers. Add personal records only to your private copy.

- `LEADS.csv` — businesses and outreach status
- `FOLLOW_UPS.csv` — approval-first follow-up queue
- `JOBS.csv` — verified job records
- `APPLICATIONS.csv` — application drafts and outcomes
- `CV_PROFILES.csv` — user-owned CV profile metadata, not CV files
- `ACTIVITY_LOG.csv` — auditable actions
